> 更新时间：2026-04-14  
> 对齐原则：**以当前代码实现为唯一事实来源**（Code as Source of Truth）

## 1. 架构与模块口径（统一）

### 1.1 主工程（根目录聚合）
- 根 `pom.xml` 为 Maven 聚合工程（`packaging=pom`）
- 聚合模块：
  - `WxFbsir-admin`
  - `WxFbsir-framework`
  - `WxFbsir-system`
  - `WxFbsir-quartz`
  - `WxFbsir-generator`
  - `WxFbsir-common`
  - `WxFbsir-business`

### 1.2 独立工程
- `WxFbsir-engine` 为**独立部署**工程，不在根聚合模块内
- `WxFbsir-ui` 为前端工程（Vue 3 + Vite）

### 1.3 启动入口
- Admin 启动类：`WxFbsir-admin/src/main/java/com/wx/fbsir/WxFbsirApplication.java`
- Engine 启动类：`WxFbsir-engine/src/main/java/com/wx/fbsir/engine/WxFbsirEngineApplication.java`
- 前端入口：`WxFbsir-ui/src/main.js`

## 3. 配置键与路径口径（统一）

### 3.1 Engine 重连配置键
以 `WxFbsir-engine/src/main/resources/application.yml` 为准：
- `max-retries`
- `initial-delay`
- `max-delay`
- `backoff-multiplier`

### 3.2 Admin 配置文件路径
统一使用：
- `WxFbsir-admin/src/main/resources/application.yml`
- `WxFbsir-admin/src/main/resources/application-druid.yml`

### 3.2.1 JDBC 与中文编码（必查）
- **JDBC URL** 中 `characterEncoding` 必须为 **`UTF-8`**（大写），勿使用小写 `utf8`，以免与 MySQL 历史 `utf8`(utf8mb3) 混淆导致菜单/业务中文变成 `???`。
- **Druid**：在 `DruidProperties` 中对连接执行 `SET NAMES utf8mb4 COLLATE utf8mb4_unicode_ci`，与会话、表 `utf8mb4_unicode_ci` 一致。
- **Spring**：`spring.servlet.encoding` 启用 UTF-8 并 `force: true`，保证请求/响应层一致。
- **已乱码数据**：执行 `sql/update_20260414_修复菜单与白名单中文乱码.sql`（或备份后按需 UPDATE），客户端使用 `--default-character-set=utf8mb4`。

### 3.3 文档链接路径
Engine 相关主文档统一位于：
- `docs/功能说明/engine/Playwright框架完整指南.md`
- `docs/功能说明/engine/WebSocket通信完整指南.md`

### 3.4 HTTP 纳管主机（OpenClaw / Hermes）口径
- **数据表**：`ws_host_whitelist`，字段 `host_type` 为 `openclaw` 或 `hermes` 且已配置 `health_check_url` 时，参与定时与手动 HTTP 健康检查。
- **Mapper**：`WsHostWhitelistMapper#selectHostsForHttpHealthCheck()`（**非**历史方法名 `selectOpenclawHosts`）。
- **定时任务类名**：`OpenClawHealthChecker`（类名沿用，实现已覆盖 OpenClaw 与 Hermes）。
- **周期与规则**：约 30s；GET；连接/读取超时 5s；HTTP **2xx** → `online_status=online`。
- **后端接口**：`HostWhitelistController`，前缀 `/business/host/whitelist`；导出为 **`POST /export`**（与前端 `proxy.download` / `whitelist.js` 一致）。
- **自动化测试**：`WxFbsir-business/src/test/java/.../OpenClawHealthCheckerTest`、`WsHostWhitelistMapperIT`、`HostWhitelistControllerStandaloneTest`。
