# 全局一致性对齐说明

> 更新时间：2026-04-12  
> 对齐原则：**以当前代码实现为唯一事实来源**（Code as Source of Truth）

---

## 1. 架构与模块口径（统一）

### 1.1 主工程（根目录聚合）
- 根 `pom.xml` 为 Maven 聚合工程（`packaging=pom`）
- 聚合模块：
  - `WxFbsir-admin`
  - `WxFbsir-framework`
  - `WxFbsir-system`
  - `WxFbsir-quartz`
  - `WxFbsir-generator`
  - `WxFbsir-common`
  - `WxFbsir-business`

### 1.2 独立工程
- `WxFbsir-engine` 为**独立部署**工程，不在根聚合模块内
- `WxFbsir-ui` 为前端工程（Vue 3 + Vite）

### 1.3 启动入口
- Admin 启动类：`WxFbsir-admin/src/main/java/com/wx/fbsir/WxFbsirApplication.java`
- Engine 启动类：`WxFbsir-engine/src/main/java/com/wx/fbsir/engine/WxFbsirEngineApplication.java`
- 前端入口：`WxFbsir-ui/src/main.js`

---

## 2. 版本口径（统一）

- **主干工程版本**：`1.0.0`
  - 来源：根 `pom.xml`、`WxFbsir-ui/package.json`、Admin 配置
- **Engine 节点版本**：`1.3.1`
  - 来源：`WxFbsir-engine/pom.xml` 的 `engine.version`

### 文档书写规范
- 禁止在部署文档硬编码历史版本号（如 `1.2.6` / `1.6.5`）
- Engine JAR 统一写法：`wxfbsir-engine-[engine.version].jar`

---

## 3. 配置键与路径口径（统一）

### 3.1 Engine 重连配置键
以 `WxFbsir-engine/src/main/resources/application.yml` 为准：
- `max-retries`
- `initial-delay`
- `max-delay`
- `backoff-multiplier`

### 3.2 Admin 配置文件路径
统一使用：
- `WxFbsir-admin/src/main/resources/application.yml`
- `WxFbsir-admin/src/main/resources/application-druid.yml`

### 3.3 文档链接路径
